The WiJungle App complements the WiJungle appliance, allowing administrators and users to monitor and manage network activities on the go.

## Overview

The **WiJungle App** empowers network administrators with real-time monitoring, management, and reporting tools for network security. Designed to integrate seamlessly with the WiJungle Unified Security Platform, the app ensures accessibility, convenience, and mobility for critical cybersecurity tasks.

---

## Features

- **Real-Time Monitoring**: Track network activity, user sessions, and bandwidth usage.  
- **Access Management**: Manage user permissions, session policies, and network rules.  
- **Security Alerts**: Receive live alerts for security breaches, vulnerabilities, or unusual activities.  
- **Reports and Analytics**: Access detailed reports for usage patterns, security incidents, and performance metrics.  
- **Remote Configuration**: Modify firewall rules, policies, and network settings from anywhere.  
- **User-Friendly Interface**: An intuitive dashboard for easy navigation and insights.  
- **Integration**: Works seamlessly with WiJungle hardware appliances.  

---

## System Requirements

- **Operating Systems**: iOS (13.0 and above) | Android (5.0 and above).  
- **Network**: Active internet connection.  
- **WiJungle Device**: Requires an active WiJungle appliance with configured credentials.

## Installation

Follow these steps to install and configure the WiJungle App:

1. **Download**:  
   - Android: [Google Play Store](#)  
   - iOS: [Apple App Store](#)  

2. **Install**: Follow on-screen instructions to install the app.  

3. **Login**:  
   - Launch the app.  
   - Enter your **WiJungle Appliance IP** and **Admin Credentials**.  

4. **Connect**: Securely connect to your WiJungle Gateway and start managing your network.

---

## Usage

1. **Login**: Enter your appliance credentials to access the dashboard.  
2. **Monitoring**: Navigate to the "Monitoring" tab to view live stats, users, and performance.  
3. **Alerts**: Review security or network alerts on the notifications screen.  
4. **Configuration**: Use the "Settings" tab to update policies, firewall rules, and access permissions.  
5. **Reports**: Generate and export network or security reports in PDF or Excel formats.  

For advanced configurations, refer to the [WiJungle Documentation](#).

## Troubleshooting

- **Issue**: Unable to connect to the appliance.  
  - **Solution**: Verify appliance IP, credentials, and network connectivity.  

- **Issue**: App crashes or becomes unresponsive.  
  - **Solution**: Ensure the app is updated and restart your device.  

- **Issue**: Incorrect security alerts.  
  - **Solution**: Verify firewall rules and anomaly detection settings on the appliance.  

For more troubleshooting steps, consult the [WiJungle Help Center](#).
